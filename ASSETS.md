Assets in this repository are self-contained. No third-party equipment photographs, manufacturer logos or remote font requests are used.

Public alt text and caption identify it as an illustration. |
| Category artwork and line icons in `scripts/build.mjs` | Original inline SVG paths and CSS patterns. Decorative equipment/application symbols, not engineering drawings or technical specifications. |

The website makes no claim of manufacturer affiliation or image-based proof of availability. Retain the font license when redistributing the outlined wordmark. The source image remains outside the deployment package; the optimized derivatives are the website assets.
